# AR-Security-Project

## Description

This project is an Augmented Reality security system.

The system detects objects using computer vision and provides security information based on predefined rules.

## Security Module

The security module contains:

- Security rules and data
- Risk scores
- Object status
- Security descriptions
- Integration and testing

## Supported Objects

The current security data includes:

- Laptop
- Cell phone
- Bottle
- Cup
- Person
- Backpack

## Technologies

- Python
- JSON
- OpenCV
- YOLO
- Augmented Reality
